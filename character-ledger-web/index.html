Formulas

Write how each derived stat is worked out. Use core stat names (bonuses included), LVL for level, and other derived names. Operators are + - * / % ^ and ( ). Functions are min, max, round, floor, ceil, abs, sqrt, pow, clamp, ln and log. The Max column caps the result.

Bonuses

From race, class, attribute, profession and title

Choose which stats each one raises or lowers. Bonuses to a core stat feed the formulas. Bonuses to a derived stat are added to its result. The Max column still caps the total. Skills and traits can list bonuses on their own cards, but those are only shown there. They never change your stats.
